## Présentation du Portfolio de Kiyane MEHAH

Ce projet consiste à créer un site web personnel permettant de présenter mon parcours, mes compétences, mes projets et mes expériences professionnelles.
Le projet est réalisé dans le cadre de ma **3e année de BUT Sciences des données**.

## Objectifs
- Présenter mon parcours et mes compétences.
- Présenter mes différents projets.
- Mettre en avant les technologies utilisées.
- Créer un site clair et facile à utiliser.
- Mettre en place une base de données pour stocker les informations du site.

## Technologies
Les technologies utilisées seront notamment :
- HTML / CSS
- JavaScript
- PostgreSQL
- Git / GitHub
- Technologie serveur : à définir

## Structure du site
Le site sera composé de plusieurs sections :
- Accueil
- Compétences
- Projets
- Formation
- Expériences professionnelles
- Contact

## Base de données
Un schéma relationnel sera réalisé afin de définir la structure de la base de données.
La base de données sera ensuite créée avec PostgreSQL et contiendra les informations nécessaires au fonctionnement du site.

Le projet est versionné avec Git. Des commits réguliers seront réalisés afin de suivre l'évolution du projet et de garder un historique des différentes étapes.
